# Finnish Industry Turnover per Employee

A comparison of turnover per employee across Finnish industries, using official enterprise statistics.

The dashboard divides each industry's total turnover by its number of employees to compare how much revenue different industries generate per person employed.

## Data
Figures are based on Finland in Figures 2024, an official publication drawing on Statistics Finland's enterprise statistics, covering enterprise counts, personnel, and turnover by industry.

The dataset contains 11 industries.

## Run locally

```bash
pip install -r requirements.txt
streamlit run app.py
```

## Tech
Python, pandas, Streamlit, Plotly
